项目介绍
${projectName}是一个Apisix的webui界面,该项目使用apisix的管理API(即数据面API)实现了对apisix实例的业务操作!
项目主要功能包括
  • 基于管理API的Route,StreamRoute等增删改查
  • 多Apisix实例管理
  • 批量删除规则
  • 一键清空所有规则
  • Apisix接口数据导入导出
  • 结合acme.sh实现DNS-01的证书申请
  • 结合acme4j实现HTTP-01的证书申请
  • 自签名证书管理
  • 过期证书自动续签
  • 基于yaml文件的发布管理

    常见问题
  • 如何打开apisix的Admin API?
  • apisix默认端口有哪些?
  • - 9180 管理API端口 eg. curl http://127.0.0.1:9180/apisix/admin/plugins/list --header 'X-API-KEY: edd1c9f034335f136f87ad84b625c8f1'
  • - 9090 控制API端口 eg. curl http://127.0.0.1:9090/v1/schema
  • - 9091 指标端口 eg. curl http://127.0.0.1:9091/apisix/prometheus/metrics
  • - 9080 流量端口(http)
  • - 9443 流量端口(https)
  • - 9100 流量端口(stream)
